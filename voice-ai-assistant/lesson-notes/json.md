Introduction to JSON

1. What is JSON?

JSON stands for JavaScript Object Notation. It is a format
used to store and exchange data between programs.

Although its name includes JavaScript, JSON is language-
independent. This means that programming languages such
as Python, Java and JavaScript can all work with JSON data.

2. Understanding JSON Structure

A JSON object is surrounded by curly braces {} and made up
of properties.

Each property consists of a key and a value, separated by a
colon.

{
    "full_name": "John Doe",
    "age": 30,
    "is_student": false
}

"full_name" is a key and "John Doe" is its value.

JSON keys must always be enclosed in double quotation marks.

{
    "programming_languages": [
        "Python",
        "JavaScript",
        "Java"
    ]
}

The programming_language key contains an array with three
strings.
